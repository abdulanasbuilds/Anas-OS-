# Evidence

The evidence authority defines how ANAS OS distinguishes facts, observations, assumptions, inferences, decisions, unknowns, and verified execution.

Evidence strength:

- E0 — none
- E1 — reasoned
- E2 — source-backed
- E3 — execution-backed
- E4 — production-backed

A stronger claim requires evidence appropriate to that claim. Missing evidence is never silently treated as proof.
