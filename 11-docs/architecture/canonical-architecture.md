# Canonical Architecture

## 1. One OS
ANAS OS is the sole authority. The numbered directories are structural layers, not independent operating systems.

## 2. Layers
- `00-foundation`: constitution, authority, governance, evidence, identity.
- `01-kernel`: canonical objects/state plus decision, risk, approval, policy, gate, lifecycle and audit/event engines.
- `02-domains`: native business/product/execution/engineering/AI/data/research/customer/integration/operations/security/growth/finance/legal/communication/content/portfolio/experimentation/automation/infrastructure/vendor/support/continuity/governance/evolution capabilities.
- `03-workflows`: cross-domain executable protocols.
- `04-contracts`: stable interfaces and validation contracts.
- `05-templates`: repeatable project, agent, workflow, research and business starting points.
- `06-knowledge`: durable organizational knowledge, patterns, lessons and playbooks.
- `07-runtime`: executable ANAS OS engines, adapters, orchestration, tools and CLI.
- `08-projects`: isolated state/evidence for individual initiatives.
- `09-tests`: verification suite.
- `10-tooling`: bootstrap, validation, generation, migration and maintenance tools.
- `11-docs`: human-readable architecture, protocol, guide and decision documentation.

## 3. Agent System
`02-domains/agent-system` is the embedded successor to the existing Agent OS. It is not a separate authority. The Agent System consumes kernel-governed state and produces auditable execution records.

## 4. Execution loop
`objective → context → plan → authority check → tool/action → verify → evidence → state/event → handoff/escalation → measurement → learning`.

## 5. Domain ownership
Domains own capability knowledge and procedures. Kernel owns universal state/policy/authority mechanics. Workflows coordinate domains. Contracts define boundaries. Runtime executes the approved mechanics.

## 6. No UI in core
UI, frontend applications, dashboards and presentation components are explicitly outside this core repository. The core must remain usable by CLI, agents, automation and external applications through stable contracts.
