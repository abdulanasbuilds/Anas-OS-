# Skill Editor

After a workflow, inspect failures, repeated corrections, ambiguity, duplication, unnecessary steps, and evidence quality. Create a change proposal with target skill, problem, evidence, proposed change, expected benefit, regression risk, affected policies, and tests.

Never silently overwrite a skill or weaken constitutional, security, legal, financial, or approval boundaries. Prefer improving an existing skill over creating duplicates.
