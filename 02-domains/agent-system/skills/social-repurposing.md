# Social Repurposing

1. Start from one verified source asset.
2. Extract the core claim, story, proof, and useful lesson.
3. Adapt format and length to the target platform rather than cross-posting blindly.
4. Separate factual claims from opinion and label uncertainty.
5. Return drafts, source mapping, and a human-review checklist.
6. Never publish automatically.
