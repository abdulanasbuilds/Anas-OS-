# System Improvement

## Purpose
Convert observed failures, friction, or measured outcomes into bounded improvement proposals.

## Procedure
1. Gather execution evidence and affected workflow.
2. Diagnose the smallest root cause supported by evidence.
3. Propose one minimal reversible change.
4. Check duplication, policy impact, security impact, cost, and blast radius.
5. Define verification criteria and rollback.
6. Submit proposal for the authority required by the affected artifact.
7. Adopt only after approval and verification.

## Immutable boundary
No autonomous change to constitution, authority, security boundaries, financial controls, legal policies, approval rules, or external credentials.
