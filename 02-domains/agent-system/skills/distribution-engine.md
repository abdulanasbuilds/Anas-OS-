# Distribution Engine Skill

Use this skill to design a long-game distribution system without confusing views with trust or revenue.

## Process

1. Define audience, problem, positioning, and value type: utility or entertainment.
2. Select channels and platform-specific packaging.
3. Build a repeatable content cadence.
4. Record reach, retention, shares, saves, repeat exposure, qualified inbound, branded discovery, and conversions where available.
5. Run bounded experiments on topic, hook, format, packaging, channel, CTA, and cadence.
6. Review opportunity flow: customers, talent, partnerships, press, mentors, and deal flow.
7. Capture learning and improve the next cycle.

## Guardrails

- No invented attribution.
- No external publishing without authority.
- Optimize for compounding trust and useful outcomes, not vanity metrics alone.
- Exact touchpoint heuristics are hypotheses unless validated with first-party evidence.
