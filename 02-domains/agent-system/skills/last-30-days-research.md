# Last-30-Days Research

1. Define the question and exact time window.
2. Collect dated primary or high-quality secondary evidence.
3. Separate new developments from older background.
4. Summarize implications, anomalies, opportunities, and unknowns.
5. Cite the source trail in the evidence record.
6. Never imply web access or current data when the required adapter is not configured.
