# Workflow Capture

Extract trigger, outcome, steps, decisions, inputs, outputs, tools, owners, dependencies, exceptions, evidence, approvals, cadence, and failure/recovery. Preserve the source. Mark missing information as `unknown` and produce questions. Never invent requirements.

A capture is a proposal until validated and registered as an approved workflow.
