# ANAS OS Agent Skills

Skills are executable operating instructions, not autonomous authority. Each skill is bounded by the constitution, agent contracts, policy engine, and approval rules.

## Built-in skills

- `personal-advisor` — structured strategic reasoning using operator context.
- `workflow-capture` — normalize a rough workflow into an inspectable proposal.
- `skill-editor` — propose evidence-based skill improvements.
- `research-briefing` — build recurring intelligence plans and evidence requirements.
- `chief-of-staff` — extract commitments, blockers, risks, and follow-ups.
- `content-repurposing` — create platform-aware drafts without auto-publishing.

Use `node 07-runtime/cli.mjs skill list` to inspect the registry. Skills never grant tool authority; permissions remain with the Agent System and kernel.
