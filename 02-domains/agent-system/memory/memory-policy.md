# Memory Policy

ANAS OS memory has three classes: stable context, working context, and learnings.

Rules:

1. Never store secrets, authentication tokens, private keys, or unnecessary sensitive data.
2. A learning starts as `proposed`; explicit approval is required before it becomes approved memory.
3. Memory never changes the constitution, authority, security boundaries, legal controls, or financial controls.
4. Prefer short, atomic learnings with source and confidence.
5. Review/archive stale learnings instead of allowing unlimited growth.
