# System Evolution

ANAS OS improves through evidence, not unrestricted self-modification.

## Loop

```text
Measure → Detect gap → Preserve evidence → Propose change → Assess impact → Review/approve → Implement → Verify → Record learning
```

The System Evolution domain may propose improvements to workflows, policies, contracts, agent behavior, tooling, and structure. It may not silently change Constitution, authority boundaries, approval classes, or security controls.

Every material improvement records the observed problem, evidence, proposed change, affected components, risks, expected outcome, verification method, result, and follow-up.
