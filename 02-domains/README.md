# Native Domains

Domains are capability areas inside the single ANAS OS. They do not own their own policy engines, approval systems, lifecycles, or constitutional authority.

Business, Product, Agent System, Engineering, AI, Data, Research, Customer, Integration, Operations, Security, Growth, Finance, Legal, Communication, Content, Portfolio, Experimentation, Automation, Infrastructure, Vendors, Support, Continuity, and System Evolution are all native domains.
